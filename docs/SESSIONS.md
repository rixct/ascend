# Учебные сессии — ASCEND 0.3.1

При создании задачи укажите время одной сессии и плановое число сессий. Число обязательно: по умолчанию 1, минимум 1. Его можно ввести с клавиатуры или изменить кнопками минус/плюс. Поля количества дней нет.

План — ориентир, а не условие автоматического закрытия. Можно записать 5 сессий по 25 минут сегодня, ещё 3 завтра: в задаче сохранятся 8 сессий и 200 минут. Можно продолжать даже после достижения или превышения плана.

При сохранении обычной сессии тумблер «Задача выполнена / Quest completed» по умолчанию выключен. Для завершения задачи включите его при сохранении последней сессии. До этой явной отметки задача остаётся доступной для дальнейшей работы. Для привычек сохраняется ежедневная отметка выполнения.

Количество сохранённых сессий и план видны в таблице Quests; в подробностях задачи также отображаются общее время и прогресс относительно плана. XP начисляется за фактически записанную практику по существующим правилам.

Старые задачи получают план в одну сессию без сброса истории. Новое поле planned_sessions сохраняется в SQLite и JSON-экспорте и восстанавливается после перезапуска и импорта. Файлы и команды без этого поля совместимы с новой версией.

Проверены Rust-тестами 5 сессий в первый день и 3 в следующий, повторная отправка одной записи, отсутствие автоматического закрытия и ручное завершение. Интеграционные тесты проверяют сохранение, экспорт/импорт, старые данные и отклонение некорректных количеств. В интерфейсе проверены значение по умолчанию 1, запрет нуля, сохранение задачи с несколькими сессиями, сохранение открытого статуса при достижении плана и ручной перевод в Completed.

```sh
./native/tests/run-sessions.sh
./scripts/cargo.sh test --workspace --locked
```
