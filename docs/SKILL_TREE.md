# Дерево навыков — ASCEND 0.3.0
Нажатие на узел выбирает навык. Его дерево квестов открывается отдельной кнопкой Quest tree / Дерево квестов. Для нового подтверждения навыка необходимо выполнить все его квесты. См. [деревья квестов](QUEST_TREES.md).

Откройте **Skills / Навыки** и нажмите кнопку **Skill tree / Дерево навыков** в правой части toolbar, рядом с добавлением навыка. Назад можно вернуться кнопкой со стрелкой.

Связи берутся из поля **Prerequisite / Зависимость** при создании навыка. Существующие данные менять или переносить не нужно. Поддерживаются ветвления и объединение нескольких обязательных навыков.

- Синий узел: навык доступен для практики и подтверждения результата.
- Зелёный: у навыка есть хотя бы один подтверждённый результат. Это не означает, что развитие навыка завершено.
- Серый: навык пока недоступен.

Выбор узла подсвечивает путь обязательных навыков. Справа показаны XP, число подтверждённых результатов, выполненные и оставшиеся требования, а также навыки, которые он открывает. Требование выполняется после подтверждения хотя бы одного результата в каждом обязательном навыке; XP сам по себе не открывает зависимые навыки. Правило и итоговая доступность берутся из существующего Rust-движка.

Из панели можно перейти к обязательному или зависимому навыку и открыть форму подтверждения результата. После сохранения статусы и требования обновляются сразу. Поиск показывает до восьми совпадений; Enter выбирает первое. Внизу графа — уменьшение, показ дерева целиком и увеличение. По большой карте можно перемещаться трекпадом или полосами прокрутки.

Дизайн поддерживает светлую и тёмную темы и русский/английский язык. Цвет сопровождается статусом и значком; заблокированные узлы остаются доступными для выбора.

Геометрия графа кэшируется по структуре зависимостей и не перестраивается при тиках таймера. Соединения рисуются в размере видимой области, карточки вне неё не создают тяжёлые представления. Раскладка не использует рекурсию и проверена на цепочках и лесах из 1000 навыков. Повреждённые связи и циклы не вызывают бесконечного обхода.

Проверки:

```sh
./native/tests/run-skill-tree.sh
./native/tests/run-notifications.sh
./native/tests/run-stability.sh
```

Тесты графа проверяют уровни, ветвления, несколько обязательных навыков, отсутствие пересечений карточек, изменение структуры, кэш, повреждённые ссылки, циклы и длинные цепочки. Отдельная проверка через реальный движок проверяет различие XP и мастерства, открытие только после всех условий, сохранение данных и удаление зависимостей.
