# Ежедневная рутина — ASCEND 0.6.0

При первом запуске после имени и оформления появляется шаг **Create your daily routine / Создайте ежедневную рутину**. Введите свои пункты и нажмите **Get started**. Пустые дополнительные строки не сохраняются. **Set up later / Настроить позже** позволяет перейти в приложение без рутины. Дальше список меняется в блоке **Daily routine / Ежедневная рутина** на Today / Сегодня: плюс открывает поле в этом же блоке, Enter сохраняет пункт, правый клик открывает удаление. Отдельного окна редактирования нет.

Рутина содержит от 1 до 12 пунктов с уникальными названиями длиной до 100 символов. Отмечайте выполненные пункты переключателями справа. Сегодняшнюю отметку можно отменить, например при ошибочном нажатии. Повторная отправка той же отметки не меняет результат. Отметки других дней через интерфейс редактировать нельзя.

## Дисциплина

Для каждого включённого дня доля выполнения равна числу отмеченных пунктов, делённому на общее число пунктов этого дня. Результат рутины — среднее этих долей за последние 28 календарных дней, включая сегодня. Все дни имеют одинаковый вес, даже если количество пунктов менялось.

- Если есть и оценённые планы, и рутина: **дисциплина = 60% индекса планов + 40% выполнения рутины**.
- Если есть только рутина: дисциплина полностью определяется её выполнением. Например, 2 из 4 пунктов в первый день дают 50, все четыре — 100.
- Если рутины нет: сохраняется прежний индекс планов — 70% выполнения обязательств, 20% регулярности и 10% точности оценки времени.

Сегодня входит в расчёт сразу. Утренняя оценка отражает ещё невыполненные пункты и растёт по мере отметок. Дни до создания рутины и дни приостановки не оцениваются. Пропущенные дни учитываются и тогда, когда приложение не открывалось. За выполнение рутины XP не начисляется; ранее заработанный XP сохраняется.

Рутина повторяется каждый календарный день, включая дни без плана задач. Список составляется один раз и остаётся тем же. Отметки относятся только к текущему дню: на следующий день чекбоксы сбрасываются, а пункты остаются. Удаление последнего пункта выключает список с сегодняшнего дня. Прошлые дни сохраняют свои списки и отметки.

## Изменения и история

Первая рутина начинает действовать сегодня. Новый пункт сразу попадает в сегодняшний список, и его можно отметить. Повторное редактирование заменяет сегодняшний список и все следующие дни. Дни до сегодняшнего сохраняют прежний список и свои отметки.

Рутина хранится локально в SQLite вместе с профилем. JSON-экспорт и резервные копии включают версии списка и отметки по дням. CSV по-прежнему предназначен для сессий; импорт CSV сохраняет существующую рутину профиля. Старые профили и JSON без полей рутины открываются без миграции и без навязанного списка.

Настройка первого профиля и создание рутины сохраняются одной транзакцией: при ошибке данные не остаются наполовину созданными. При смене календарного дня интерфейс получает новый список без переноса вчерашних отметок.

Поддерживаются русский и английский языки. Формула также описана в **Settings → Rules / Настройки → Правила**.

Проверки:

```sh
./scripts/cargo.sh test --workspace --locked
./scripts/cargo.sh clippy --workspace --all-targets --locked -- -D warnings
./native/tests/run-routine.sh
./native/tests/run-stability.sh
```
