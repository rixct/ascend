# Уведомления ASCEND 0.2.3

Настройки находятся в **Настройки → Уведомления / Settings → Notifications**. Значения сохраняются и применяются сразу. У пунктов настроек используются системные SF Symbols.

## Разрешение и предупреждения

Уведомления по умолчанию выключены. Первое включение запрашивает разрешение macOS. Если они выключены внутри ASCEND либо запрещены системой, отображается восклицательный знак: у настроек профиля, в переключателе разделов настроек и в статусе уведомлений.

После отказа приложение не повторяет системный запрос. В настройках появляется кнопка перехода в настройки уведомлений macOS. Разрешение перепроверяется при возвращении в приложение; отдельно доступна кнопка проверки. Выключение отменяет ожидающие уведомления ASCEND.

## Сценарии

| Уведомление | По умолчанию | Поведение |
| --- | --- | --- |
| Фокус-сессия | Включено | Один сигнал по окончании оценки времени квеста. Пауза отменяет сигнал; продолжение пересчитывает оставшееся время. Завершение сессии и полноценный выход отменяют сигнал. Задача сама не закрывается, XP автоматически не начисляется. |
| План на день | 09:00 | Предлагает выбрать до трёх квестов или отдых. Принятый план, включая день отдыха, отменяет напоминание на этот день. При уже открытой сессии напоминание о плане на сегодня не назначается. |
| Сроки квестов | 18:00 | Одно объединённое уведомление о незакрытых квестах со сроком сегодня. В тексте — до трёх названий. Закрытые или удалённые квесты исключаются. Просроченные задачи не создают повторяющихся тревог. |
| Вечерний обзор | Выключено, время 20:30 | Предлагает короткую запись в журнале. Если запись за день уже есть, напоминание отменяется. |

Для трёх дневных сценариев можно отдельно менять время и включение. Звук настраивается независимо от самих уведомлений.

Тихие часы по умолчанию — **22:00–08:00**. Напоминание, попавшее в этот промежуток, пропускается и не переносится на утро. Поддерживаются интервалы через полночь; одинаковые начало и конец означают нулевую длительность. Проверочное уведомление запускается явно кнопкой, через три секунды, поэтому тихие часы его не блокируют.

## Доставка и переходы

Используется системный `UserNotifications`, без сервера и push-аккаунта. Дневные напоминания назначаются на семь дней вперёд; расписание обновляется при работе приложения, изменении настроек, даты или часового пояса. Уже назначенные дневные напоминания могут доставляться после закрытия ASCEND. Если приложение не открывать дольше семи дней, нужно запустить его для обновления расписания.

Обычное закрытие окна с включённым режимом работы в фоне оставляет работающую сессию. Полный выход останавливает её и отменяет её уведомление. Системные режимы фокусирования macOS могут скрывать баннеры; ASCEND их не обходит.

Нажатие уведомления открывает соответствующий раздел: фокус и план — обзор, сроки — квесты, вечерний обзор — журнал, проверка — настройки уведомлений. Выполненные напоминания удаляются из ожидающих; неактуальные доставленные уведомления очищаются при обновлении состояния.

## Проверки

- Сборка Swift с предупреждениями как ошибками, проверка подписи `.app` и ресурсов RU/EN.
- Тесты: семь дней расписания, уникальные идентификаторы, выполненные планы и записи, объединение сроков, пауза/продолжение, истёкшее время, ночные и дневные тихие часы, звук, переход на летнее время, сохранение настроек.
- Существующие проверки стабильности: IPC, восстановление таймера, массовый ввод, освобождение ресурсов, импорт/экспорт.
- В изолированной копии проверены обычный запуск, окна настроек, русская локализация, выключение и состояние «Запрещены в macOS» с восклицательным знаком. Настройки основного приложения и личный профиль не изменялись.

Автоматизированная проверка самой доставки баннера ограничена: инструмент управления запрещает доступ к системному диалогу `UserNotificationCenter`. Разрешение для рабочего ASCEND должен подтвердить пользователь; после этого доставку можно проверить кнопкой в настройках. Фактическое появление баннера в этой проверке не заявляется.

Тесты после сборки:

```sh
./native/tests/run-notifications.sh
./native/tests/run-stability.sh
```

Реализация разрешений и планирования следует API Apple: [разрешения](https://developer.apple.com/documentation/usernotifications/asking-permission-to-use-notifications), [локальные уведомления и отмена](https://developer.apple.com/documentation/usernotifications/scheduling-a-notification-locally-from-your-app).
