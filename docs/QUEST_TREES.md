# Деревья квестов — ASCEND 0.4.1

Откройте **Skills → Skill tree / Навыки → Дерево навыков**, затем выберите навык и нажмите кнопку **Quest tree / Дерево квестов** в его панели. Нажатие на сам узел только выбирает навык. Кнопка «Все навыки» или стрелка назад возвращает к общему дереву.

Внутри — граф зависимостей с поиском, масштабом, подсветкой пути и панелью выбранного квеста. Зелёные квесты выполнены, синие доступны, серые ещё заблокированы. Есть отдельные статусы паузы, отмены и работы. Наверху отображается число выполненных квестов этого навыка.

## Зависимости и создание

Поле **Depends on / Зависит от** находится в основной части формы квеста. Можно выбрать квест своего навыка или другого навыка; необязательная зависимость по умолчанию — «Нет». Для новых квестов отменённые и пропущенные варианты не предлагаются.

Кнопка **Add next quest / Добавить следующий квест** подставляет навык текущего дерева и выбранный родительский квест. Навык и зависимость можно изменить до создания. Обычная кнопка добавления квеста в toolbar также подставляет текущий навык.

Внешние обязательные квесты и их предки показаны на графе со значком перехода. В подробностях указан исходный навык и есть кнопка его открытия. Внешние квесты не увеличивают счётчик квестов текущего навыка.

## Подтверждение навыка

Новое подтверждение возможно, только когда выполнены условия открытия навыка и все принадлежащие ему квесты. Кнопки блокируются во всех нативных экранах и форме подтверждения; то же правило проверяется Rust-движком.

- Обычная задача или этап засчитывается после явного завершения. XP, записанное время, частичные сессии и достижение планового числа сессий сами по себе не означают выполнение квеста.
- Отменённые, пропущенные и поставленные на паузу невыполненные квесты не засчитываются. В дереве отменённый или пропущенный квест можно вернуть в план, затем выполнить.
- Повторяющаяся привычка засчитывается после первой сохранённой отметки выполнения. Она остаётся повторяющейся и не обязана получать постоянный статус Completed. Это же правило действует для зависимостей от привычки.
- Навыки без квестов сохраняют возможность ручного подтверждения результата.

Уже подтверждённые результаты и XP сохраняются. Если добавить новый квест, следующее подтверждение станет доступно после его выполнения; история подтверждений не удаляется.

## Работа с квестом

Из дерева можно начать сессию, записать время или открыть текущую фокус-сессию. Сохранение обычной сессии по-прежнему не закрывает задачу без ручной отметки. После завершения квеста обновляются зависимости, прогресс навыка и доступность подтверждения.

## Проверки

```sh
./native/tests/run-quest-tree.sh
./native/tests/run-skill-tree.sh
./native/tests/run-sessions.sh
./native/tests/run-stability.sh
./native/tests/run-notifications.sh
./scripts/cargo.sh test --workspace --locked
./scripts/cargo.sh clippy --workspace --all-targets --locked -- -D warnings
```

Проверены вложенная область навыка, внешние предки, ветвления, объединённые зависимости, повреждённые ссылки, циклы и 1000 узлов; запрет подтверждения до завершения всех квестов, частичные сессии, отмена, привычки и перезапуск. В интерфейсе проверен переход 2/4 → 3/4 → 4/4, подтверждение и открытие следующего навыка, затем создание нового зависимого квеста с возвратом к 4/5 и блокировкой нового подтверждения.

Оба вида деревьев используют общий отрисовщик видимой области, нативную прокрутку и кэш геометрии. Формат зависимостей уже существовал; перенос базы не требуется.
